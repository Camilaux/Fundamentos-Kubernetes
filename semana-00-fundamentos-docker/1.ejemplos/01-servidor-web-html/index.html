¡Hola desde tu Contenedor!

Si estás viendo esta página web servida por Nginx, significa que tu imagen de Docker fue empaquetada correctamente y está corriendo con éxito.

¿Qué acaba de ocurrir por debajo?
  1. Docker leyó el Dockerfile.
  2. Descargó la capa base oficial de nginx:alpine.
  3. Copió este archivo index.html dentro de /usr/share/nginx/html/.
  4. Expuso el puerto 80 y dejó el proceso escuchando en primer plano.
