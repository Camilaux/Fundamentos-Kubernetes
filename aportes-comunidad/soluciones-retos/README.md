# 🏆 Soluciones de Retos de la Comunidad

¡Este es el espacio donde los asistentes del workshop comparten las soluciones a los **Retos Rotos** de cada semana!

---

## 📌 ¿Cómo subir tu solución?

1. **Crea tu carpeta personal:**
   Dentro de esta carpeta, crea una estructura con tu nombre de usuario de GitHub y la semana correspondiente:
   ```text
   aportes-comunidad/soluciones-retos/<tu-usuario-github>/semana-01/
   ```

2. **Copia y corrige el manifiesto:**
   * ⚠️ **Importante:** Nunca modifiques los archivos originales dentro de las carpetas semanales `semana-XX/2.reto-roto/`.
   * Pega tu solución corregida dentro de tu carpeta (por ejemplo: `01-pod-solucionado.yaml`).
   * Agrega comentarios `#` en el YAML explicando:
     * ¿Cuál era el error original?
     * ¿Cómo lo detectaste? (`kubectl describe`, `kubectl logs`, etc.)
     * ¿Cómo lo solucionaste?

3. **Envía tu Pull Request:**
   Sigue los pasos de [`CONTRIBUTING.md`](../../CONTRIBUTING.md).
   * 🤖 **¡Completamente automático!** Cuando un mentor apruebe y fusione tu PR, un bot de GitHub Actions actualizará automáticamente tu rango en [`ASISTENTES.md`](../../ASISTENTES.md) (de **⛵ Marinero** a **🧭 Timonel** o **⚓ Capitán K8s**) y te felicitará en el Pull Request.
